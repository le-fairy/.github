르페어리는 조향사가 직접 설계한 향으로 잠자리, 손끝, 공간의 공기를 바꾸는 향 브랜드입니다.

이 조직은 그 향을 **온라인에서 팔고**, **이벤트로 경험하게 하는** 일을 코드로 풉니다.
향은 화면에 그릴 수 없습니다. 그래서 우리는 향수병 대신 향이 지나간 공기를 만듭니다.

<br />

## 우리가 푸는 문제

| 영역 | 하는 일 |
| :-- | :-- |
| **커머스** | 자사몰 상세페이지와 기획전, 메타 카탈로그와 네이버 스마트스토어 채널 연동 |
| **이벤트** | 한정 향 사전예약 랜딩, 시즌 캠페인 페이지 |
| **브랜드 사이트** | 회사 소개 사이트와 모바일 페이지 |

## 일하는 방식

**디자인.** 향을 그리지 않고 향이 지나간 공기를 그립니다. 한 화면에는 기억될 것 하나만 둡니다.

**커밋.** 바뀐 것을 기능별로 나눠 따로 커밋하고, 제목은 `feat: 기능 이름` 처럼 씁니다.

**비밀키.** `.env`, 서비스 계정 키, API 키는 절대 커밋하지 않습니다.
